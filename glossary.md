git add - готовит к передаче файл
git commit - подписывает и запечатывает 
git push - отправляет данные в ветку гита
git status - показать состояние репозитория (в какой ветке находимся, есть ли новые коммиты). Например:
'On branch main
Your branch is ahead of 'origin/main' by 1 commit.
  (use "git push" to publish your local commits)'

nothing to commit, working tree clean
branch - ветка. например: On branch main
main - имя ветки локального репозитория
origin - имя ветки репозитория в гите
